# 🎵 AiuraSound – Mood-Based Music Recommender with Explainable AI

AiuraSound is an intelligent music recommendation system that analyzes a user's mood from text input and suggests songs accordingly. It combines **Machine Learning (ML)** for mood classification and **Generative AI (GenAI)** for explanation, making the system both accurate and interpretable.

---

## 🚀 Features

- 🎯 Mood detection from natural language input  
- 🎶 Song recommendations based on predicted mood  
- 🧠 Explainable AI – shows *why* a mood was predicted  
- 💬 AI-based assistant for mood understanding (optional)  
- ⚡ Lightweight and fast (runs locally)  
- 🌐 Interactive UI using Streamlit  

---

## 🧠 Tech Stack

### Machine Learning
- Random Forest Classifier (scikit-learn)
- Feature-based mood prediction using audio attributes

### Generative AI
- Flan-T5 (Hugging Face Transformers)
- Rule-based explanation system
- FAISS

### Other Tools
- Python  
- Pandas, NumPy  
- Streamlit  
- Joblib  
- PyTorch
